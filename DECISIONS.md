# Decisions Log — hotel-demos

Autonomous judgment calls made while building this project, and anything that needs owner confirmation.

## Le Blanc Bleu

- **Pool**: Google Maps lists a pool for this property, but leblancbleu.com does not mention one. Per instructions, the pool is NOT mentioned anywhere in the demo copy. **Needs owner confirmation** before adding.
- **Hero video**: Chose Pexels video ID 28954960, "Breathtaking Sunset Over Mediterranean Sea" by Vizual Production (https://www.pexels.com/video/breathtaking-sunset-over-mediterranean-sea-28954960/, https://www.pexels.com/@vizualproduction). Pexels License (free for commercial/personal use, no attribution required, per Pexels license terms). Downloaded the 1920x1080/25fps file. Calm open sea, golden-hour sun reflection, small distant breakwaters only — no people, boats, text, or logos. Source clip trimmed to 12s and made into a seamless loop via a 1s xfade crossfade of the tail into the head (ffmpeg xfade filter).
- **Owner photos**: Scraped the exact image files referenced in leblancbleu.com's own homepage HTML/CSS (images/1.jpg, 1-2.jpg, 1-3.jpg, 1-4.jpg, 2.jpg, bg2019new.jpg, bg20193.jpg — logo and preloader/favicon assets excluded). All 7 are ≥1500px wide and usable. These are the owner's own photography, used only in this private, noindexed preview addressed to the owner.
- **Photo 1-2.jpg** shows a small temporary/portable frame pool and a stone fountain basin in the garden. Per the hard content rule, no pool is mentioned in any copy (Google Maps lists a pool but the owner's own site text does not). The photo is still used for its sea-view terrace framing; needs owner confirmation on whether to keep, recrop, or replace once real photography/confirmation is available.
- **Photo 2.jpg** (sunset with a distant cargo ship silhouette) used only as a smaller supporting image, not the hero, since a ship in frame slightly undercuts the "private secluded escape" pitch.
- **Brand name in Arabic copy**: Kept "Le Blanc Bleu" in Latin script throughout the Arabic page (hero, about, meta, WhatsApp message, demo banner, alt text) instead of a phonetic Arabic transliteration ("لو بلان بلو"). Mixed-script brand names are standard practice in Lebanese hospitality/retail marketing, and a phonetic transliteration read as machine-translated rather than natural, which conflicts with the "natural Lebanese-market MSA" requirement.
- **Lighthouse SEO score**: Expected to be flagged/capped because of the intentional `<meta name="robots" content="noindex, nofollow">` in demo mode — this is correct behavior for a private preview and is not something to "fix"; it will resolve itself when `demo` is set to `false` at launch.
- **Final Lighthouse scores (mobile, run against the live URL)**: Performance 93, Accessibility 100, Best Practices 100, SEO 66 (single audit failing: "Page is blocked from indexing", i.e. the intentional noindex tag above — every other SEO audit passes). One optimization pass was needed to hit the performance target: removed a redundant hidden poster `<img>` competing with the video's own poster for the largest-contentful-paint slot, deferred `video.play()` to JS instead of a static `autoplay` attribute, and shrank `poster.jpg`/`poster.webp` from ~243KB to ~49KB. This took mobile Performance from 81 to 93.
